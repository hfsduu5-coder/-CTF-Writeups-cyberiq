# Writeup Quality Gate

Use this checklist before marking a writeup complete.

- [ ] Platform/event and category are named.
- [ ] Authorization/scope is explicit.
- [ ] Objective is clear.
- [ ] Facts are separated from hypotheses.
- [ ] Key evidence is preserved or described.
- [ ] Methodology explains reasoning, not only commands.
- [ ] Solution is reproducible inside the authorized challenge environment.
- [ ] Root cause or core concept is explained.
- [ ] Defensive takeaway is included.
- [ ] Flag publication follows event/platform rules.
- [ ] No real credentials, API keys, private data, or unrelated target details are present.
- [ ] Missing historical details are marked unknown rather than invented.

A writeup that fails the publication gate remains a draft or practice note.
