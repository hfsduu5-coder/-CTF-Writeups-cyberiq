# Case File — Keyed Permutations
**Status:** VERIFIED REFERENCE
**Platform:** CryptoHack
**Track:** Symmetric Ciphers / How AES Works
**Official source:** https://cryptohack.org/challenges/aes/

## Objective
Understand AES as a keyed permutation over fixed-size blocks.

## Investigation path
1. Identify the fixed block size.
2. Distinguish a permutation from an arbitrary mapping.
3. Relate invertibility to decryption under the same key.
4. Validate the concept in the official challenge.

## Defensive takeaway
AES security depends on strong keys and correct modes of operation, not secrecy of the cipher design.
